End the service for {{.Code}} from this appliance. Nothing here is triggered by the provider: you decide, and the appliance does the rest.

What happens

  1. PSA work stops at once. No further connection tests or ticket synchronization.
  2. The Control Plane is told over this appliance's own machine certificate. It deletes every record it holds about this deployment (reports, heartbeats, inventory, commands, certificates, packages, the deployment itself) in one transaction and keeps one audit event that says the client deleted it.
  3. Everything on this appliance is deleted: tickets, ticket history, the encrypted PSA credentials, logs, synchronization state, local administrator accounts, the report outbox, the license token and the machine identity.
  4. You remove the containers. The appliance cannot delete its own Docker resources; the final page shows the one command that does, from the package folder on this host.

If the Control Plane cannot be reached, the appliance keeps trying; the local deletion starts only after the Control Plane confirmed, unless you decide otherwise on the next page.

Confirm

Irreversible. There is no backup on the Control Plane: it never holds ticket data or credentials.
