# Module Implementation Plan & Backlog

Modules 1–10 are the MVP. **Architecture constraint (mandatory):** the operational PSA application runs in each client's Docker deployment; the Control Plane is a management plane only (ARCHITECTURE AD-11–AD-13, §1.1). **No module is marked Complete while any of its required tests are failing or blocked.** Each module ends with a completion report (`docs/reports/MODULE-NN.md`).

**Order (approved 2026-10-14):** Module 5 was built before Module 4 to reach the first milestone (two Docker client installations on one dashboard) sooner. The milestone path is 5 → 6 → 7 → 8 → 9 → 10. Module 4 (catalog administration) was not on it, because the catalog was already database-driven and assignable; it was delivered right after Module 10.
